## 翻译原则

1. **准确性第一**: 确保技术术语翻译准确，必要时保留英文原文
2. **保持格式**: 保留reStructuredText格式，确保文档能正确构建
3. **术语一致性**: 使用统一的术语翻译，参考`glossary.rst`
4. **可读性**: 在准确的基础上，确保中文表达通顺自然

## 如何贡献

如果您想参与翻译工作，请：

1. 查看`translation_list.txt`文件，选择要翻译的文件
2. 翻译时请遵循上述翻译原则
3. 翻译完成后进行校对
4. 提交您的翻译
