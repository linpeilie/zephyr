.. _cpu_load_metric:

CPU负载 (CPU Load)
###################

CPU负载子系统返回当前CPU自上次调用以来的CPU负载百分比 (The CPU Load subsystem returns the CPU load as a percentage for the current CPU, since the last time it was called)。

有关CPU负载子系统的示例,请参阅 :zephyr:code-sample:`cpu_freq_on_demand` 示例 (For an example of the CPU Load subsystem refer to :zephyr:code-sample:`cpu_freq_on_demand` sample)。
