序列化 (Serialization)
######################

Zephyr 支持多个数据序列化子系统。这些可用于在线上以已知格式编码/解码结构化数据。(Zephyr has support for several data serialization subsystems. These can be used to encode/decode structured data with a known format on-the-wire.)
