.. _bluetooth-features:

支持的功能
##################

.. contents::
    :local:
    :depth: 2

自诞生以来,Zephyr 一直非常关注蓝牙,特别是低功耗蓝牙(LE)。通过参与蓝牙规范
现有开源实现(Linux 的 BlueZ)的多家公司和个人的贡献,以及低功耗蓝牙无线电硬件
的设计和开发,Zephyr 中的协议栈已经发展成为成熟且功能丰富,如下面部分所示。

* 符合蓝牙 v5.3 规范

  * 高度可配置

      * 功能、缓冲区大小/数量、堆栈大小等。

  * 可移植到 Zephyr 支持的所有架构(包括大端和小端、对齐方式等)

  * 支持主机和控制器构建的 :ref:`所有组合 <bluetooth-hw-setup>`:

    * 仅控制器(HCI),通过 UART、SPI、USB 和 IPC 物理传输
    * 仅主机,通过 UART、SPI 和 IPC(共享内存)
    * 组合(主机 + 控制器)

* :ref:`蓝牙 SIG 可认证 <bluetooth-qual>`

  * 一致性测试定期在所有层(控制器和主机,除了 BT Classic)上在 Nordic
    Semiconductor 硬件上运行。

* :ref:`低功耗蓝牙控制器 <bluetooth-ctlr-arch>` (LE 链路层)

  * 无限的角色和连接数,支持所有角色
  * 支持所有 v5.3 规范功能(除了少数次要项目)
  * 并发多协议支持就绪
  * 智能角色调度以最小化重叠
  * 可移植设计到任何开放的低功耗蓝牙无线电,目前支持 Nordic Semiconductor
    nRF52x 和 nRF53x SoC 系列,以及专有无线电
  * 支持小端和大端架构,并抽象硬实时细节,以便将它们封装在特定于硬件的模块中
  * 支持通过不同物理传输的控制器(HCI)构建
  * 同步通道

* :ref:`蓝牙主机 <bluetooth_le_host>`

  * 通用访问配置文件(GAP),支持所有可能的 LE 角色

    * 外设和中心
    * 观察者和广播者
    * 多 PHY 支持(2Mbit/s、编码)
    * 扩展广播
    * 周期性广播(包括同步传输)

  * GATT(通用属性配置文件)

    * 服务器(作为传感器)
    * 客户端(连接到传感器)
    * 增强 ATT (EATT)
    * GATT 数据库哈希
    * GATT 多重通知

  * 配对支持,包括蓝牙 4.2 的安全连接功能

  * 非易失性存储支持,用于蓝牙特定设置和数据的永久存储

  * 蓝牙 Mesh 支持

    * 中继、朋友节点、低功耗节点(LPN)和 GATT 代理功能
    * 支持两种配网角色和承载(PB-ADV 和 PB-GATT)
    * 包括基础模型
    * 高度可配置,适合小至 16k RAM 的设备

  * 基本蓝牙 BR/EDR(经典)支持

    * 通用访问配置文件(GAP)
    * 逻辑链路控制和适配协议(L2CAP)
    * 串口仿真(RFCOMM 协议)
    * 服务发现协议(SDP)

  * 清晰的 HCI 驱动程序抽象

    * 3-Wire (H:5) 和 5-Wire (H:4) UART
    * SPI
    * 本地控制器支持作为虚拟 HCI 驱动程序

  * 已通过多个流行控制器验证
  * 同步通道
  * :ref:`LE 音频 <bluetooth_le_audio_arch>`
