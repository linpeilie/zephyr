.. _usbc_vbus_api:

USB-C VBUS
##########

概述 (Overview)
****************

USB-C VBUS 是 USB Type-C 连接中从源设备向接收设备传递电源的线路。

.. _usbc-vbus-api:

USB-C VBUS API
==============

USB-C VBUS 设备驱动程序提供用于控制和测量 VBUS 的 API。

配置选项 (Configuration Options)
*********************************

相关配置选项:

* :kconfig:option:`CONFIG_USBC_VBUS_DRIVER`
