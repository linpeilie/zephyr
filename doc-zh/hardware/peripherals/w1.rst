1-Wire 总线 (1-Wire Bus)
##########################

概述 (Overview)
****************

1-Wire 是一种低速半双工串行总线,仅使用一根导线加地线进行数据传输和设备供电。与 I2C 类似,1-Wire 使用双向开集电极数据线,并且是单主机多点总线。这意味着一个主机启动与从设备的所有数据交换。1-Wire 总线支持比 I2C 更长的总线线路,而它在标准模式下可达到高达 15.4 kbps 的速度,在超速模式下可达到高达 125 kbps 的速度。在标准速度配置下,可以在 100 米长的总线上与 10 个节点进行可靠通信。使用超速,预计 10 米长总线上的 3 个节点可以稳定工作。优化的时序参数和总线上较少的节点可能允许达到更大的总线范围。

实现细节在 `BOOK OF IBUTTON STANDARDS`_ 中指定。

.. _w1-master-api:

W1 主机 API (W1 Master API)
============================

Zephyr 的 1-Wire 主机 API 用于与温度传感器和串行存储器等 1-Wire 从设备交互。

在 Zephyr 中,此 API 分为以下层:

* 链路层处理基本通信功能,例如总线复位、存在检测和位传输操作。它是 Zephyr 中唯一的硬件相关层。此层由使用 Zephyr :ref:`uart_api` 接口的驱动程序支持,该接口应在大多数 Zephyr 平台上工作。将来,可能会添加基于 GPIO/定时器的驱动程序和特定于硬件的驱动程序。
* 1-Wire 网络层处理从机识别和总线仲裁的所有方法。这包括 ROM 命令,如 Match ROM 或 Search ROM。

   * 所有从设备都有一个唯一的 64 位识别号,其中包括一个 8 位 `1-Wire Family Code`_ 和一个 8 位 CRC。
   * 为了在总线上查找从机,标准指定了一种搜索算法,该算法依次检测总线上的所有从机。此算法在 `1-Wire Search Algorithm Application Note`_ 中描述。

* 传输层和表示层功能未在通用 1-Wire 驱动程序中实现,因此必须在各个从机驱动程序中处理。

1-Wire API 被视为实验性的。
