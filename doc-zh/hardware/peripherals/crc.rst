循环冗余校验 (Cyclic Redundancy Check, CRC)
############################################

概述 (Overview)
****************

循环冗余校验 (CRC, Cyclic Redundancy Check) API 提供用于在硬件上配置和计算 CRC 值的函数。

配置选项 (Configuration Options)
*********************************

相关配置选项:

* :kconfig:option:`CRC_HW`
* :kconfig:option:`CRC_INIT_PRIORITY`
