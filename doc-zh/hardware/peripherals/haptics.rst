触觉反馈 (Haptics)
###################

概述 (Overview)
****************

触觉反馈 API 允许控制触觉驱动设备以执行触觉反馈事件。

在触觉反馈事件期间,触觉设备向执行器驱动信号。触觉事件信号的来源因触觉设备的功能而异。

触觉信号源的一些示例包括模拟信号、预编程 (ROM) 波表、合成 (RAM) 波表和数字音频流。

此外,触觉驱动设备通常提供用于调整和调谐驱动信号的控制,以满足其各自执行器的电气要求。
