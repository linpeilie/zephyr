时钟控制 (Clock Control)
##########################

概述 (Overview)
****************

时钟控制 API 提供对系统中时钟的访问,包括打开和关闭时钟的能力。

配置选项 (Configuration Options)
*********************************

相关配置选项:

* :kconfig:option:`CONFIG_CLOCK_CONTROL`
