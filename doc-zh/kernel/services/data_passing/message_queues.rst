消息队列
########

:dfn:`消息队列` 是一个内核对象,它实现了简单的消息队列,允许线程和 ISR
异步发送和接收固定大小的数据项。

.. contents::
    :local:
    :depth: 2

概念
****

可以定义任意数量的消息队列(仅受可用 RAM 限制)。每个消息队列由其内存地址引用。

消息队列具有以下关键属性:

* 已发送但尚未接收的数据项的**环形缓冲区**。

* **数据项大小**,以字节为单位。

* 可以在环形缓冲区中排队的数据项的**最大数量**。

消息队列在使用之前必须初始化。这会将其环形缓冲区设置为空。

数据项可以由线程或 ISR **发送**到消息队列。发送线程指向的数据项被复制到
等待的线程(如果存在);否则该项被复制到消息队列的环形缓冲区(如果有空间)。
在任何情况下,被发送的数据区域的大小*必须*等于消息队列的数据项大小。

如果线程在环形缓冲区已满时尝试发送数据项,发送线程可以选择等待空间变得可用。
当环形缓冲区已满时,任意数量的发送线程可以同时等待;当空间变得可用时,它会被
给予等待时间最长的最高优先级发送线程。

数据项可以由线程从消息队列**接收**。数据项被复制到接收线程指定的区域;
接收区域的大小*必须*等于消息队列的数据项大小。

如果线程在环形缓冲区为空时尝试接收数据项,接收线程可以选择等待数据项被发送。
当环形缓冲区为空时,任意数量的接收线程可以同时等待;当数据项变得可用时,它会被
给予等待时间最长的最高优先级接收线程。

线程还可以**窥视**消息队列头部的消息而不从队列中删除它。数据项被复制到接收
线程指定的区域;接收区域的大小*必须*等于消息队列的数据项大小。

.. note::
    内核确实允许 ISR 从消息队列接收项,但是如果消息队列为空,ISR 不得尝试等待。

.. note::
    不需要对齐消息队列的环形缓冲区。底层实现使用 :c:func:`memcpy`(它是
    对齐无关的)并且不暴露任何内部指针。

实现
****

定义消息队列
============

使用类型 :c:struct:`k_msgq` 的变量定义消息队列。然后必须通过调用
:c:func:`k_msgq_init` 初始化它。

以下代码定义并初始化能够容纳 10 个项的空消息队列,每个项长 12 字节。

.. code-block:: c

    struct data_item_type {
        uint32_t field1;
	uint32_t field2;
	uint32_t field3;
    };

    char my_msgq_buffer[10 * sizeof(struct data_item_type)];
    struct k_msgq my_msgq;

    k_msgq_init(&my_msgq, my_msgq_buffer, sizeof(struct data_item_type), 10);

或者,可以通过调用 :c:macro:`K_MSGQ_DEFINE` 在编译时定义和初始化消息队列。

以下代码与上面的代码段具有相同的效果。请注意,宏定义了消息队列及其缓冲区。

.. code-block:: c

    K_MSGQ_DEFINE(my_msgq, sizeof(struct data_item_type), 10, 1);

写入消息队列
============

通过调用 :c:func:`k_msgq_put` 将数据项添加到消息队列。

以下代码基于上面的示例,并使用消息队列将数据项从生产者线程传递给一个或多个
消费者线程。如果由于消费者无法跟上而导致消息队列填满,生产者线程会丢弃所有
现有数据,以便可以保存较新的数据。请注意,此 API 将触发重新调度。

.. code-block:: c

    void producer_thread(void)
    {
        struct data_item_type data;

        while (1) {
            /* 创建要发送的数据项(例如测量、时间戳等) */
            data = ...

            /* 将数据发送给消费者 */
            while (k_msgq_put(&my_msgq, &data, K_NO_WAIT) != 0) {
                /* 消息队列已满:清除旧数据并重试 */
                k_msgq_purge(&my_msgq);
            }

            /* 数据项已成功添加到消息队列 */
        }
    }

从消息队列读取
==============

通过调用 :c:func:`k_msgq_get` 从消息队列获取数据项。

以下代码基于上面的示例,并使用消息队列处理一个或多个生产者线程生成的数据项。
请注意,应测试 :c:func:`k_msgq_get` 的返回值,因为由于 :c:func:`k_msgq_purge`
可能返回 ``-ENOMSG``。

.. code-block:: c

    void consumer_thread(void)
    {
        struct data_item_type data;

        while (1) {
            /* 获取数据项 */
            k_msgq_get(&my_msgq, &data, K_FOREVER);

            /* 处理数据项 */
            ...
        }
    }


窥视消息队列
============

通过调用 :c:func:`k_msgq_peek` 从消息队列读取数据项。

以下代码窥视消息队列以读取一个或多个生产者线程生成的队列头部的数据项。

.. code-block:: c

    void consumer_thread(void)
    {
        struct data_item_type data;

        while (1) {
            /* 通过窥视队列读取数据项 */
            k_msgq_peek(&my_msgq, &data);

            /* 处理数据项 */
            ...
        }
    }

建议用途
********

使用消息队列以异步方式在线程之间传输小数据项。

.. note::
    如果需要,消息队列可用于传输大数据项。但是,这会增加中断延迟,因为在写入或
    读取数据项时会锁定中断。写入或读取数据项的时间随其大小线性增加,因为项的
    全部内容被复制到内存中的缓冲区或从中复制。因此,通常最好通过交换指向数据项
    的指针而不是数据项本身来传输大数据项。

    可以通过使用内核的邮箱对象类型来实现同步传输。
