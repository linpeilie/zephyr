内存板
######

:dfn:`内存板` 是一个内核对象,允许从指定的内存区域动态分配内存块。内存板中的
所有内存块都具有单一固定大小,允许它们高效地分配和释放并避免内存碎片问题。

.. contents::
    :local:
    :depth: 2

概念
****

可以定义任意数量的内存板(仅受可用 RAM 限制)。每个内存板由其内存地址引用。

内存板具有以下关键属性:

* 每个块的**块大小**,以字节为单位。它必须至少为 4N 字节长,其中 N 大于 0。

* 可用于分配的**块数**。它必须大于零。

* 为内存板的块提供内存的**缓冲区**。它必须至少为"块大小"乘以"块数"字节长。

内存板的缓冲区必须对齐到 N 字节边界,其中 N 是大于 2 的 2 的幂(即 4、8、16...)。
为了确保缓冲区中的所有内存块都类似地对齐到此边界,块大小也必须是 N 的倍数。

内存板在使用之前必须初始化。这会将其所有块标记为未使用。

需要使用内存块的线程只需从内存板分配它。当线程完成内存块后,它必须将块释放
回内存板,以便块可以重用。

如果所有块当前都在使用中,线程可以选择等待一个块变得可用。任意数量的线程可以
同时在空内存板上等待;当内存块变得可用时,它会被给予等待时间最长的最高优先级
线程。

与堆不同,如果需要,可以定义多个内存板。这允许使用较小块的内存板和其他具有
较大块的内存板。或者,可以使用内存池对象。

内部操作
========

内存板的缓冲区是固定大小块的数组,块之间没有浪费的空间。

内存板使用链表跟踪未分配的块;每个未使用块的前 4 个字节提供必要的链接。

实现
****

定义内存板
==========

使用类型 :c:type:`k_mem_slab` 的变量定义内存板。然后必须通过调用
:c:func:`k_mem_slab_init` 初始化它。

以下代码定义并初始化一个内存板,该内存板有 6 个块,每个块长 400 字节,每个块
都对齐到 4 字节边界。

.. code-block:: c

    struct k_mem_slab my_slab;
    char __aligned(4) my_slab_buffer[6 * 400];

    k_mem_slab_init(&my_slab, my_slab_buffer, 400, 6);

或者,可以通过调用 :c:macro:`K_MEM_SLAB_DEFINE` 在编译时定义和初始化内存板。

以下代码与上面的代码段具有相同的效果。请注意,宏定义了内存板及其缓冲区。

.. code-block:: c

    K_MEM_SLAB_DEFINE(my_slab, 400, 6, 4);

同样,您可以在私有作用域中定义内存板:

.. code-block:: c

    K_MEM_SLAB_DEFINE_STATIC(my_slab, 400, 6, 4);

分配内存块
==========

通过调用 :c:func:`k_mem_slab_alloc` 分配内存块。

以下代码基于上面的示例,等待最多 100 毫秒以使内存块变得可用,然后用零填充它。
如果未获得合适的块,则打印警告。

.. code-block:: c

    char *block_ptr;

    if (k_mem_slab_alloc(&my_slab, (void **)&block_ptr, K_MSEC(100)) == 0) {
        memset(block_ptr, 0, 400);
	...
    } else {
        printf("内存分配超时");
    }

释放内存块
==========

通过调用 :c:func:`k_mem_slab_free` 释放内存块。

以下代码基于上面的示例,分配一个内存块,然后在不再需要时释放它。

.. code-block:: c

    char *block_ptr;

    k_mem_slab_alloc(&my_slab, (void **)&block_ptr, K_FOREVER);
    ... /* 使用 block_ptr 指向的内存块 */
    k_mem_slab_free(&my_slab, (void *)block_ptr);

建议用途
********

使用内存板以固定大小的块分配和释放内存。

当从一个线程向另一个线程发送大量数据时使用内存板块,以避免不必要的数据复制。
