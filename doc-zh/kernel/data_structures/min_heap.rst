最小堆数据结构 (Min-Heap Data Structure)
#########################################

.. contents::
  :local:
  :depth: 2

最小堆实现提供了一种高效的数据结构,用于管理动态变化的元素列表,同时保持快速提取最小值的能力。它是一种基于树的数据结构,满足堆属性,并支持常见操作,例如插入、删除和从最小堆中弹出最小元素。

本节解释了实现背后的动机、其内部结构、API 用法以及嵌入式系统和实时环境的示例场景。

堆结构 (Heap Structure)
************************

堆作为存储在数组中的完全二叉树维护。
每个节点满足**最小堆**属性:

   - 每个节点的值小于或等于其子节点的值。

此属性确保**最小元素始终位于根部**(索引 0)。

.. code-block:: text

    Index:      0   1   2   3   4   5   6
    Values:    [1,  3,  5,  8,  9, 10, 12]

                   1
                 /   \
               3       5
              / \     / \
             8   9  10  12

对于索引 ``i`` 处的任何节点,其子节点位于以下索引:

- 左子节点: :math:`2*i + 1`

- 右子节点: :math:`2*i + 2`

其父节点位于索引:

- 父节点: :math:`(i - 1) / 2`

用例 (Use Cases)
*****************

MinHeap 非常适合:

- 实现优先级队列
- 增量排序数据
- 资源仲裁(例如,最低成本资源选择)
- 协作式多任务系统中的调度
- 管理超时和延迟队列
- 基于优先级的传感器或数据采样

在像 Zephyr 这样的 RTOS 环境中,此堆可用于内核级或应用程序级模块,其中需要以最小延迟获取最高优先级资源。
