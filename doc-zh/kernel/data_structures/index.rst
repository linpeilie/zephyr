.. _data_structures:

数据结构
########

Zephyr 提供了一个在内核中使用的通用数据结构库,但通常对应用程序代码也很有用。
这些包括用于存储有序数据的列表和平衡树结构,以及用于以简洁方式管理"字节流"
数据的环形缓冲区。

请注意,通常来说,这些集合被实现为"侵入式"数据结构。库代码使用的唯一结构是
"节点"数据,它不存储指针或其他元数据来指示该节点"拥有"哪些用户数据。相反,
期望节点本身嵌入在用户定义的结构中。提供宏以从嵌入的节点指针以简洁的方式
检索用户结构地址。此设计背后的目的是允许在不允许动态分配的上下文中使用集合
(即不需要分配节点对象,因为内存由用户提供)。

还要注意,这些库通常是不同步的;默认情况下,对它们的访问不是线程安全的。这些是
数据结构,而不是同步原语。期望任何需要的锁定都由用户提供。在特定使用场景中,
提供的一些数据结构是线程安全的(请参阅 :ref:`spsc_lockfree` 和
:ref:`mpsc_lockfree`)。
